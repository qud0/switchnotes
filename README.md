# SwitchBook — Интерактивная записная книжка коммутаторов

Автономное локальное приложение для сетевых инженеров и системных администраторов для наглядного ведения коммутаторов, портов и VLAN **без фонового мониторинга, опроса по сети или SNMP**.

Специально адаптировано для оборудования **MikroTik**, **SNR (NAG)** и **Ubiquiti (UniFi / EdgeSwitch)**, а также поддерживает любые другие вендоры.

---

## Ключевые возможности

1. **Реалистичная лицевая панель (Switch Faceplate)**:
   * 19-дюймовый корпус в индустриальном стиле со стойковыми «ушами» (rack ears), светодиодами состояния (`PWR`, `SYS`, `SPEED`, `PoE`), вендором и моделью устройства.
   * Двухрядная раскладка медных портов RJ-45 (нечетные сверху `1, 3, 5...`, четные снизу `2, 4, 6...`).
   * Корзины оптических портов SFP / SFP+ Uplink.
   * Родная нумерация интерфейсов вендоров (`ether1` / `sfp-sfpplus1` для MikroTik, `GigabitEthernet 1/0/1` для SNR, `Port 1` для Ubiquiti).

2. **Наглядная работа с VLAN и транками**:
   * **Access-порты**: порт и его бейдж окрашиваются в персональный цвет VLAN.
   * **Trunk-порты**: маркировка `TRK`, полосатый паттерн, Native VLAN и список Tagged (Allowed) VLAN.
   * **Подсветка VLAN (VLAN Highlighter)**: выбор нужного VLAN мгновенно подсвечивает все порты, через которые он проходит, приглушая остальные.
   * **Групповая настройка портов**: возможность выделить несколько портов (например, 1–12) и назначить им VLAN, режим или описание в один клик.

3. **Межкоммутаторные связи и Агрегация каналов (LACP / LAG / Bonding)**:
   * Прямая связь порта с портом другого свитча.
   * **Объединение портов в LAG**: поддержка агрегированных каналов (`Port-Channel` для SNR, `/interface bonding` для MikroTik, `LAG` для UniFi).
   * Визуальный бейдж `L1`, `L2` на портах и отображение статуса агрегации в тултипе.
   * Кнопка быстрого перехода к удаленному коммутатору прямо из тултипа.
   * **Детектор расхождений (VLAN Mismatch)**: предупреждает значком `⚠️` о забытых VLAN в транке или несовпадении Native VLAN.

4. **Интерактивная карта топологии сети (Topology Map)**:
   * Переключение в режим **«Топология»** в шапке программы.
   * Автоматическое построение графа сети по настроенным межкоммутаторным связям.
   * Свободное перетаскивание узлов мышкой (Drag & Drop) с сохранением позиций.
   * Индикация типа линка: **10G SFP+ (магистрали)** и **1G RJ45 (медь)** с бейджами портов.
   * **Трассировка VLAN (VLAN Path Tracing)**: выбор конкретного VLAN подсвечивает путь его движения через коммутаторы и линки, приглушая неиспользуемые участки сети.
   * Клик по линку открывает боковую карточку с деталями: порты на обоих концах, разрешенные VLAN и статус коллизий.

5. **Генератор команд CLI (MikroTik, SNR, Ubiquiti)**:
   * Кнопка **«CLI Конфиг»** генерирует готовый текстовый файл команд для вставки в терминал коммутатора:
     * RouterOS v7 Bridge VLAN Filtering (`/interface bridge vlan`, `/interface bridge port`);
     * SNR CLI (`switchport mode access/trunk`, `switchport trunk allowed vlan`);
     * Ubiquiti EdgeSwitch / UniFi CLI.

5. **Визуальная серверная 19" стойка (Rack Elevation 42U)**:
   * Переключение в режим **«Стойка 42U»** в шапке программы.
   * Автоматическая группировка устройств по стойкам и шкафам (`unit 1` ... `unit 42`).
   * Наглядная занятость шкафа и быстрый переход к коммутаторам.

6. **Кабельный журнал и экспорт в Excel (CSV)**:
   * Вкладка **«Кабельный журнал (Таблица портов)»** рядом с лицевой панелью.
   * Поиск, фильтры по режимам (Access, Trunk, Линки, PoE).
   * Экспорт таблицы коммутации в файл CSV (с поддержкой UTF-8 BOM для Microsoft Excel).

7. **Быстрый импорт из текстового конфига**:
   * Кнопка **«Импорт»** в шапке позволяет вставить вывод `show running-config` или `export` — система сама создаст коммутатор и настроит все порты за 1 секунду.

8. **Светлая и темная тема**:
   * Поддержка светлой темы (матовый алюминий) и темной темы (глубокий slate/графит).
   * Шрифты **Ubuntu Sans** и **Ubuntu Mono**.

---

## Быстрый запуск

### Windows (В один клик):
Запустите файл **`start.bat`**. Он запустит сервер и откроет программу в браузере по адресу `http://localhost:3001`.

### Через терминал:
```bash
npm start
```
или для разработки:
```bash
npm run dev
```
